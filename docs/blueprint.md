# **App Name**: WebNexus

## Core Features:

- Personalized Web Hub: A customizable dashboard for users to organize and quickly access their favorite websites and online resources.
- Embedded Content Viewer: Display web pages from configured URLs within an iframe or similar web component, allowing quick viewing without leaving the app's interface.
- Quick Search & Navigation: A prominent search bar to rapidly navigate to URLs or perform web searches using a pre-selected search engine.
- Bookmark Manager: Ability to add, categorize, and efficiently access saved web links, including custom labels and notes.
- AI-Powered Content Summary Tool: An AI tool to generate concise summaries of embedded web pages on demand, helping users quickly grasp key information.
- User Preferences & Layout Customization: Allow users to personalize the visual layout, theme, and organization of their web hub for an optimized personal experience.

## Style Guidelines:

- The visual scheme embraces a dark mode to promote focus and reduce eye strain for extended personal use.
- Primary interactive elements and highlights are in a rich, thoughtful violet: #8033CC.
- The background offers a deep, calming hue visibly derived from the primary violet, ensuring a cohesive dark ambiance: #1D1B22.
- An analogous, vibrant blue serves as the accent, providing clear visual contrast for critical actions and alerts: #3B58DB.
- All text uses 'Inter' (sans-serif), chosen for its modern, neutral, and highly readable characteristics, suitable for both headlines and body content in a focused browsing environment.
- Minimalist and clean line-style icons for navigation, bookmarks, and other interactive elements, ensuring clarity without visual clutter.
- A responsive, customizable dashboard layout featuring a persistent left sidebar for navigation and quick links, with a central content area for embedded web views.
- Subtle and fluid transitions for state changes and content loading, enhancing user interaction without distracting from the primary browsing experience.
