
# WebNexus App Shell - מדריך הפעלה והמרה

הפרויקט הזה הוא מעטפת "קיוסק" מוגנת המיועדת להרצת אפליקציות HTML מקומיות (מתיקיית ההורדות) או אתרים מרחוק.

## איך מורידים את הפרויקט?
לחץ על כפתור **"Download as ZIP"** בפינה הימנית העליונה של ממשק ה-Firebase Studio, וחלץ את הקבצים במחשב שלך.

## שלב 1: הכנה ראשונית (במחשב שלך)
1. וודא שמותקן אצלך **Node.js**.
2. פתח טרמינל (CMD) בתיקייה שחילצת והרצ:
   ```bash
   npm install
   ```

## שלב 2: הרצה כגרסת ווב (דפדפן)
כדי לראות את האתר במחשב בזמן פיתוח:
```bash
npm run dev
```
הכנס לכתובת `http://localhost:9002` בדפדפן.

## שלב 3: המרה לאנדרואיד (Android APK)
1. צור גרסה סופית:
   ```bash
   npm run build
   ```
2. הוסף את אנדרואיד (פעם אחת בלבד):
   ```bash
   npx cap add android
   ```
3. סנכרן את הקוד:
   ```bash
   npx cap sync android
   ```
4. פתח ב-Android Studio כדי לייצר את ה-APK:
   ```bash
   npx cap open android
   ```
   בתוך Android Studio, לחץ על **Build > Build APK**.

## שלב 4: המרה לווינדוס (Windows EXE)
מומלץ להשתמש ב-**Tauri**:
1. `npm install --save-dev @tauri-apps/cli`
2. `npx tauri init` (בחר בתיקיית `out` כתיקיית המקור).
3. `npx tauri build`

---

## הערות חשובות:
- **נתיבים מקומיים:** באנדרואיד, השתמש בנתיב: `file:///storage/emulated/0/Download/FOLDER/index.html`.
- **ניהול:** לחיצה ארוכה (5 שניות) בפינה השמאלית התחתונה של המסך תפתח את ממשק המנהל.
- **מיקרופון:** המערכת מוגדרת לאפשר שימוש במיקרופון לכל האפליקציות הפנימיות ללא בקשות חוזרות.
